# YuTu

REST API для блоговой платформы с системой комментариев и рейтингов. Разработано на Node.js с использованием Express.js.

## 🛠 Технологии

- **Node.js** - среда выполнения JavaScript
- **Express.js** - веб-фреймворк для Node.js
- **Nodemon** - автоматическая перезагрузка сервера при изменениях

## 📦 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/Deloperr/YuTu.git

# Перейти в папку проекта
cd YuTu

# Установить зависимости
npm install

# Установить dev-зависимости
npm install nodemon --save-dev
