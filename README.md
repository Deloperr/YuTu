# БлогПлатформа

Блоговая платформа с системой комментариев и рейтингов.

Express 5 + EJS + PostgreSQL, перед приложением стоит nginx (reverse proxy).

## Возможности

- Список постов со средним рейтингом, числом комментариев и просмотров (`GET /`)
- Детальная страница поста с комментариями и оценками 1–5 (`GET /item/:id`, `POST /item/:id/comments`)
- Форма добавления поста — только для «авторизованного» пользователя (`GET /add`, `POST /add`)
- У каждой записи выводится время создания с точностью до секунд, поэтому одинаковые по тексту записи различимы
- Страницы ошибок 404, 400 и 500; ссылки на них — в подвале сайта (`/error/500`, `/error/500-db`)
- Данные хранятся в PostgreSQL

## Middleware

| Файл | Назначение |
|---|---|
| `middleware/logger.js` | метод, URL, время, IP; после ответа — статус и длительность |
| `middleware/securityHeaders.js` | общие заголовки ответа |
| `middleware/locals.js` | helper-функции для шаблонов (`formatDate`, `plural`) |
| `middleware/auth.js` | `identifyUser` — авторизация по `?auth=1` (запоминается в cookie); `requireAuth` — редирект на `/login` |
| `middleware/errorHandlers.js` | `notFound` (404) и `errorHandler` (4 параметра: 500/400, логирование, запасная HTML-страница) |

## Проверки формы (сервер)

Все поля проверяются на сервере (`validators/`), браузерная валидация отключена (`novalidate`),
поэтому сообщения одинаковые в любом браузере. Ограничения продублированы в БД через `CHECK`.

| Поле | Правила |
|---|---|
| Заголовок | обязательное; не только пробелы; 5–120 символов; должно содержать буквы/цифры |
| Автор / имя | обязательное; 2–50 символов; только буквы, пробел, дефис, апостроф, точка; начинается с буквы |
| Категория | только значение из списка (подмена значения отклоняется) |
| Время чтения | целое число ≥ 0 без дробей/экспоненты/знака, диапазон 1–300 |
| Текст поста | обязательное; 20–5000 символов |
| Комментарий | обязательное; 3–1000 символов |
| Оценка | целое число 1–5 |

Дополнительно: пробелы по краям обрезаются, повторяющиеся пробелы схлопываются; управляющие символы и повтор
одного поля в запросе отклоняются; повторная отправка того же поста (тот же заголовок и автор за минуту) блокируется;
тело запроса ограничено 20 КБ (иначе страница 400/413). Весь вывод в шаблонах экранируется (`<%= %>`).

## Запуск

Требуется Node.js ≥ 18, PostgreSQL, nginx (`brew install nginx`).

```bash
npm install
cp .env.example .env      # при необходимости поправить доступ к PostgreSQL
npm run db:init           # создаст БД blog_platform, таблицы и начальные данные
npm start                 # Express на http://localhost:3000
npm run nginx:start       # nginx на http://localhost:8088 → проксирует на :3000
```

Открыть **http://localhost:8088**.

Прочие команды: `npm run dev` (перезапуск при изменениях), `npm run db:reset` (пересоздать таблицы),
`npm run nginx:stop`, `npm run nginx:reload`, `npm run nginx:test`.

## Структура

```
server.js              настройка Express, порядок middleware
config/db.js           пул подключений PostgreSQL
db/schema.sql, seed.sql
scripts/init-db.js     создание БД и таблиц
middleware/            логирование, авторизация, ошибки, helpers
validators/            правила проверки форм
models/                SQL-запросы
controllers/           обработчики маршрутов
routes/index.js        маршруты
views/                 EJS-шаблоны (partials/, index, item, add, login, 404, 400, 500)
public/                CSS и JS (nginx отдаёт напрямую)
nginx/nginx.conf       конфигурация reverse proxy
```
